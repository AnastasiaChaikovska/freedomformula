# Symbols

The **Elements of freedom**: the logo's open isometric box with each element's symbol rising out of it, plus the four stages of the box opening. All are 64×80 SVGs (exported at 128×160) with the box in `violet`, the symbol in `magenta` and sparks in `ember`. For other colours, use the inline version (`.ff-glyph`, which follows `currentColor`).

| File | Element | English |
| --- | --- | --- |
| flame-fr | Свобода | Freedom (always the sum) |
| layers-kn | Знання | Knowledge |
| cube-pr | Практика | Practice |
| steps-me | Наставництво | Mentorship |
| network-co | Спільнота | Community |
| coins-in | Дохід | Income |
| arrow-wi | Воля | Will |
| sprout-st | Старт | Fresh start |
| fork-ch | Вибір | Choice |
| box-closed → box-lifting → box-spark → box-flame | The box story | always in this order |

Use them at 24px and up. Below 32px, drop the back edges. Always pair a glyph with the element's name.
