# Icons

Outline icons on a 24px grid with round caps; the paths come from the site's inline SVG. The files are drawn in `ink` (#170b36), and `arrow-up-right` in `violet`. Inline them with `stroke="currentColor"` to recolour, at stroke 2.2.

- `arrow-right`: forward actions on buttons.
- `arrow-up-right`: links that go elsewhere (`ff-link`); it nudges diagonally on hover.
- `arrow-left`: the "← Головна" back link on project pages.
- `menu`: the mobile navigation toggle.
- `close`: the modal close button.
