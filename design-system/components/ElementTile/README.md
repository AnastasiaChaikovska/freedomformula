# ElementTile

One cell of the brand's own periodic table, the **Elements of freedom**: a small number, the element's glyph (the open box with its symbol rising out of it) as the main image, and the element's full name. There are no letter abbreviations: the glyph is the symbol.

| № | Element | Glyph |
| --- | --- | --- |
| 00 | Свобода / Freedom | flame (the logo) |
| 01 | Знання / Knowledge | stacked plates |
| 02 | Практика / Practice | small cube |
| 03 | Наставництво / Mentorship | steps up to a spark |
| 04 | Спільнота / Community | three linked dots |
| 05 | Дохід / Income | coin stack |
| 06 | Воля / Will | arrow up and out |
| 07 | Старт / Fresh start | sprout |
| 08 | Вибір / Choice | fork |

- Variants: `ff-el` (light), `ff-el--night`, and `ff-el--key` for Freedom (violet → magenta, always the centre or the first cell). A tile with `aria-pressed="true"` turns violet; that is the selected state in the formula builder.
- **Свобода is never one of the parts.** It is always on the left of "=".
- Glyph files are in `assets/Symbols/`; the inline versions come from `glyph()` and are coloured by `.ff-glyph` classes.
