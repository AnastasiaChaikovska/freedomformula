# Quote

Three ways to set a statement apart from body text.

| Class | Look | Use |
| --- | --- | --- |
| `ff-quote` | 22px/600 `ink` beside a 4px rule in the violet → magenta gradient | Stance lines ("Ми не рятуємо жінок."). `ff-quote--fire` on Chaos Formula pages. |
| `ff-callout` | A `violet-tint` box, `radius-md` | A short aside or conclusion. `ff-callout--fire` for Chaos Formula. |
| `ff-pillar` | A numbered row under a hairline | The "У що ми віримо" beliefs list. |

Use «…» quotes in Ukrainian and “…” in English.
