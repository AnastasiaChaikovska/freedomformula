# FeatureTile

A tile on a night section, used for the four meanings of freedom in "Why Freedom Formula".

- `night-raised` fill, a faint violet inner edge, `radius-lg`. On hover the edge brightens and a violet glow drops below.
- Number in `violet-bright`, title in `on-night`, text in `on-night-muted`.
- Copy pattern: "Для когось це…" / "For some, it is…".
