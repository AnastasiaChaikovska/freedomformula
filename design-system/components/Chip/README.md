# Chip

A small uppercase pill that labels a section or marks something new; the one place `radius-full` is used besides dots.

- `ff-chip`: `violet-tint` fill, `violet` text (6.1:1). It sits above section titles.
- `ff-chip--fire`: `fire-tint` fill, `fire-deep` text, `fire-border` outline. Use it for Chaos Formula and "new".
- `ff-chip--night`: translucent violet on night sections.
- `ff-spark` is the ember dot, the brand's spark of fire. Add `ff-spark--live` to make it pulse (it stops under reduced motion), or use `ff-spark--violet` for a calm violet dot.
