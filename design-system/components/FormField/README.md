# FormField

A label above a rounded-box input, select or textarea.

- Label: `label` style in `ink`, sentence case, no colon. This replaces the old uppercase labels.
- Control: `radius-md`, a 1px `border-strong` edge (`violet-200` on hover). On focus the edge becomes 1.5px `violet` with a 4px `violet-tint` halo.
- 15px text (use 16px on mobile so iOS doesn't zoom).
