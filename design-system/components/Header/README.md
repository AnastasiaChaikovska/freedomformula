# Header

A sticky white bar, 72px tall, with the logo mark and a two-line display wordmark, rounded nav pills, the language switch and the CTA.

- Nav links are `text`; on hover they turn `violet` on a `violet-tint` pill.
- The Chaos Formula link is `fire-red` with a live ember spark. It is the only red on the main site's chrome.
- Project pages swap the nav for "← Головна" plus the page's anchors, and use the fire language switch and button.
- Below 900px, collapse the nav into a menu button (`assets/Icons/menu.svg`); keep the language switch visible.
