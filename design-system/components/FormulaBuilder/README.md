# FormulaBuilder

**«Склади свою формулу».** The visitor taps elements and sees their own formula assemble: *Моя формула свободи: Свобода = Дохід + Воля*. It is the site's copy ("Ми не знаємо універсальної формули… хочемо, щоб жінки знайшли свою") turned into something you do, and the result is shareable.

- Left: eight `ff-el--night` toggle tiles (`aria-pressed`). Right: a `night-raised` result card with the live formula, a hint and "Поділитися формулою".
- It lives in the night "Формула" section and replaces the four static freedom tiles.
- For sharing, generate a 1080×1080 card: the formula on night with the flame-rise glow.
- The consumer supplies the share action.
