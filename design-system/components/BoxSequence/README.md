# BoxSequence

The logo's story told in four steps: the box is **closed**, the **lid lifts**, a **spark** appears inside, and a **flame** rises out. Use it for any process: a programme's stages, how to join, a participant's journey.

- Four `ff-boxstep` cells on a dashed connector, each with a stage glyph (`stage:closed / lifting / spark / flame`), a number, a display title and one sentence.
- Inside `.ff-fire` the glyphs and connector turn red (Chaos Formula's programme: Навчання → Практика → Ментори → ICF-коучинг).
- Always four steps and always in this order, so the flame comes last.
